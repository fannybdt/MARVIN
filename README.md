# MARVIN

This repository contains the official implementation of the paper [Generative cell phenotyping with structured latent populations](https://arxiv.org/abs/2306.10574).

## Code

The majority of the code is written in [Python](https://www.python.org). Neural networks are built and trained using the [PyTorch](https://pytorch.org/) automatic differentiation framework.

```
uv sync --extra dev
source .venv/bin/activate
```
